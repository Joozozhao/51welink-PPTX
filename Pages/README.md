# 公共页面组装站

复用统一品牌规范下的优质幻灯页，在浏览器中选页、排序、保存方案，并导出 PDF。

## 打开与使用

在仓库根目录执行：

```sh
node Pages/build/serve.mjs
```

打开 [公共页面组装站](http://127.0.0.1:4173/Pages/)。选择公共页后，给演示命名，在右侧调整顺序，预览并点击“导出 PDF”。启动后日常操作均在网页中完成。

草稿与命名方案保存在当前浏览器。下载方案 JSON 可备份或转交同事；在另一台电脑通过“导入方案”恢复。静态网页不会直接改写仓库的 `Pages/decks/`。

本机服务会生成 PDF 并修正中文字符映射；纯静态网站会打开打印视图，选择“另存为 PDF”。两种方式保留真实文字与矢量图形。浏览器打印输出的纸张比例、背景图形和边距仍需检查；本机导出使用固定 16:9 无边距页面。

## 文件与发布

- `pages.json`：公共页清单，包括标题、分类、标签、来源、HTML 和缩略图路径。
- `../shared/`：设计规范、公共页与缩略图。
- `renderer.js`：整册预览与 PDF 导出共用的组装器。
- `decks/`：随站示例方案。用户方案通过 JSON 导入/导出。
- `build/`：入库、缩略图、校验、CLI 导出与本机服务。

发布时以本仓库根目录为网站根目录，保留公共页引用的原素材路径。主资料中心有“公共页面组装站”入口。`pack.sh` 排除构建脚本、测试和构建产物；本机服务从 Git 工作副本启动，静态发布包走浏览器打印方式。

本轮交付范围为页面库、组装器和 PDF。PPTX、变量填充、多人共享存储和网页后台入库属于后续增强。

## 验收

验收覆盖混合来源、重复选页、刷新恢复、JSON 导入导出、排序与页码、异常输入、静态打印、PDF 的实际页数与中文文字覆盖，以及桌面和手机布局。实际结果记录在 `ACCEPTANCE.md`。
